# 阅读与设置

## 阅读优先

- 工具栏紧凑，字体和摘录等操作放在同一功能区域；上一篇/下一篇保留导航含义。标题上方重复来源、日期、版本提示若无决策价值可移除。
- 列表保持信息密度：来源/日期弱化，标题清楚，摘要截断，有图则显示合适缩略图；列表宽度可拖拽、可收起，阅读正文保留合理版心。
- 颜色优先兼容宿主，必要时使用插件作用域语义变量提供独立、克制的选中态。不能只换背景而忽视标题、摘要、hover、focus、暗色对比。
- Lucide 等成熟图标优先，语义准确；树代表乔木，未读不强行用邮箱。商店自定义图标能力先核实，不承诺上传 PNG。

## 频道与搜索

桌面菜单锚定触发器；手机使用适合触摸的底部面板或原生选择流程，别把桌面 hover 菜单缩小。频道按聚合、订阅分组、来源组织，有图标/缩写，长列表可搜索。搜索有清晰 x；清除后保留输入焦点，空值隐藏按钮。

每频道记住列表滚动、当前文章、正文位置、筛选和搜索。重复选择当前频道只收起菜单。文章切换立即响应，慢内容在正文局部加载；取消或丢弃过期响应。J/K 等仅在阅读上下文生效，不截获输入框、编辑器、IME 或带修饰键输入。

## 设置

使用当前 SDK 支持的原生 Setting/设置接口；按任务分阅读、来源、摘录、关于，不照搬所有项目的 tab 数。反复切换 tab 验证只有一条导航；宿主复用节点时清理自建内容，监听不要重复注册。

前台字体面板与后台共用状态，即改即保存；点击外部关闭，不加完成/保存或无需求的恢复默认按钮。面板靠近锚点并限制视口，正文滚动不把它甩出屏幕。失败保留最后有效设置并反馈。

关于：版本、更新记录、帮助、GitHub Issues、作者的公开主页。更新说明按版本展示，避免每次打开都弹公告。插件升级走宿主机制，不自更新可执行文件。普通用户不需要后端服务地址、内部 IDs 和调试开关。

## 无障碍与触摸

默认不用 title/setTooltip/悬浮说明。必要可访问名称仍必须有；若宿主会将 aria-label 转成 tooltip，可用可见文本、visually-hidden label 与 aria-labelledby。保留 focus-visible、Escape、键盘遍历和合理触摸区域。用户明确要求某个 popup 的 tooltip 只授权该表面。

移动端保留系统长按选区手柄；不要在 touchstart 全面 preventDefault，不要把整个正文 draggable。处理 selectionchange 与工具点击不丢选区；工具浮层不遮挡选择。窄屏截图只能证明布局，不能证明 iOS 原生选区、拖放、键盘。

## 空态

没有选文章时提供安静的阅读入口：一句主文案、一则可切换的功能场景、少量快捷键。不要铺大灰卡、密集说明或随机刷新内容。只有来源切换或用户点下一则时更换，重渲染保持稳定。空列表、搜索无结果、无正文、加载与错误是不同状态。
